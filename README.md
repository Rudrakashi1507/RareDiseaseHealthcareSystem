# Rare Disease Analysis and Healthcare Intelligence System

Software-based healthcare analytics and decision-support platform for analyzing rare disease information.

## Features
- Rare disease search by name and OrphaCode
- Disease details and identifiers
- Disease type and group analytics
- Age-of-onset analysis
- Similar disease identification
- K-Means disease clustering
- Interactive Streamlit dashboard
- FastAPI REST backend
- PostgreSQL database

## Technology Stack
Python, Streamlit, FastAPI, PostgreSQL, Pandas, NumPy, Scikit-learn, Plotly, SQLAlchemy, Joblib, GitHub, Render

## Dataset
The system contains 11,456 rare disease records with disease classification, identifiers, age of onset, and inheritance information.

## Disclaimer
This system is intended for healthcare analytics and decision-support purposes only. It is not intended for medical diagnosis or treatment decisions.
